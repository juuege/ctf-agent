## 题目
- 附件：0_1_Game.py（源码）+ cipher.txt（n, hint1, hint2, z, ciphertext[335]）
- 结构：n=p·q²（512bit×3）；hint1/2=(p±q)^65537 mod n；逐位 Goldwasser-Micali 型加密 c=r²·z^bit mod n（z 为 p、q 双非二次剩余），bit 取自 flag 二进制串的十进制逐位

## 解法（深通道-模型探索，纯标准库）
1. q = gcd(hint1−hint2, n)：s 奇 ⇒ (p+q)^s−(p−q)^s = 2q·(s·p^(s−1)+q²·(...))，q-adic 赋值恰 1 ⇒ 一步出 q；p = n/q²
2. 逐位判读：Legendre 符号 pow(c mod p, (p−1)//2, p)==p−1 ⇔ 该位=1（GM 判据，n=pq² 下只需 mod p）
3. ciphertext[i] 为低位序 → 逆序拼 0/1 → int(s,2) → to_bytes = flag
- 全程 assert 验证：n%q²==0、p·q²==n、335 个 Legendre 值均 ∈ {1,p−1}

## 七维标签
- 题型：crypto
- 载体/格式：py 源码 + 文本参数表（无二进制）
- 识别信号：pow((p±q),s,n) 对称双 hint + r²·z^b 逐位加密 + 1536bit 模数
- 核心技术链：gcd(对称 hint 差值)分解 → Legendre 判位 → 二进制重组
- 陷阱类型：hint1+hint2 的 gcd 不可用（p 不整除）；密文下标是低位序需逆序
- 可迁移模式：奇次幂对称双 hint 的差值 gcd = 提取 n 中单次幂素因子的单步分解器
- 变体预测：s 改偶数 → 差值各项含 p 因子、gcd 出 pq；n 改 p²q 同理；数字域扩到 0..9 按 z^m 符号判

## 每题一得
对称双 hint（(p±q)^s mod n，s 奇）的**差值 gcd** 是 n=p·q² 型模数的 O(1) 分解器；q-adic 赋值恰为 1 是不变量，与具体素数无关。
