## 已完成
1. n = (p+1)(q+1) − (p+q) − 1 = pq；令 s=p+q，判别式 s²−4n 为完全平方 → p、q 各 1024 bit。
2. d = e⁻¹ mod φ，解出明文为 base32 串（GU5DCMJ2…）。
3. base32 解码得 `5:11:AM:6:{0:9:5:2:4:4:5:1:5:7:8:6:1:2:3:2:1:9:1:5:8:2:AM:7:3:AM:1:3:4:0:2:2:}`。

## 二层判断（证据）
- 前缀 4 个 token 与 flag 逐位吻合：按 a=0、b=1…l=11（12 点记作 AM），5=f、11=l、AM=a、6=g。
- 内层 32 token，符号集 {0..9, AM}；按同一映射得 `ajfceefbfhigbcdcbjbfichadbdeacc`，26 种移位、Atbash、栅栏(2-5)、列转置(2/4/8/16)、倒序均不可读。
- base11/12/13 大整数转字节、双位打包、4bit 打包均无可打印结果；base12 全串转十进制为 34 位数字（无 checker 无法验证）。

## 失败原因
- 二层为自定义“时钟面”编码，未识别 12 以后字母/数字的表示法；无 checker 无法验证候选。
- CTFPilot fast 通道 0.6s / 32 attempts NOT SOLVED（无该检测器）。
- GitHub API 配额一度仅剩 3/60，候选仓库探测耗时增加。

## 一得
- RSA 只要泄露 p+q 与 (p+1)(q+1)，n=pq 立得，且 s²−4n 必为完全平方，可闭式分解，不必做通用大整数分解。
