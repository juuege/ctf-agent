双通道工作流

从题面路由到 RSI 闭环：快通道优先，模型探索补位，经验持续固化。

主路径 · 4 步
STEP 01

路由侦察

魔数、扩展名、内容指纹三路判定题型与置信度，先确认战场再投入预算。

STEP 02

快通道

编码链、凯撒、XOR、压缩解包等确定性检测器，毫秒到秒级，零模型调用。

STEP 03

模型探索

recall 历史经验 + 读 playbook + 自写脚本验证；卡壳 15 分钟强制转外搜，禁止盲试。

STEP 04

RSI 闭环

trace 留痕 → writeup 入库 → 同类反复命中 → 固化为确定性检测器，让下一题更快。

快通道 · 确定性路径

fastpath/detectors.py · 纯标准库
0 LLM · 秒级
  • 链式解码：Base64 / Base32 / Hex / URL / Reverse，按行拆分输入，BFS 最深 8 层。
  • 古典密码：Caesar 26 位移全扫，含 ROT13、Atbash。
  • 异或：单字节 0..255 全扫，题面 token 作密钥的 XOR。
  • 压缩解包：gzip / zlib 魔数识别，解压后自动续接链式解码。
  • 实测：6 道冒烟题全部命中，耗时 0.0–1.1 秒。

模型探索 · 深水区路径

recall + references + 自写脚本
无后端依赖
  • 知识预热：先 recall 同题型经验，再读 CLI / RSI / 检索 / 信号 playbook。
  • 脚本验证：临时依赖装 .temp/，不污染全局；每步打印可读证据。
  • 信号题：先采样级相位定调制，再找自描述引导头读参数，避免先入为主。
  • 卡壳策略：15 分钟无进展或同一策略连败 2 次，立即按 extsearch 检索。
  • 看图规则：模型只做粗定位，关键判读交用户确认，避免视觉误读 flag。
可选兜底：--mode deep --brain mock 提供 12 步离线确定性策略梯（读文件 → 可见串 → 熵启发 → 解包 → 轮转），不抢主路径；LLM 后端已从 config 移除，模型探索由当前模型直接完成。

RSI 沉淀机制

北极星：更快解题
  • 留痕
    每题默认 --write-trace，题型、flag、全部尝试入库，作为复盘原材料。
  • 入库
    writeup 学习生成技能卡 + 检查点 + 经验，按题型与技术标签索引。
  • 复用
    recall 命中相似路径直接套用并验证，不从零开始。
  • 固化
    同一技术反复取用或检测器反复 miss，即编译为快通道代码资产。
  • 纪律
    每题必有一得；同一策略连败 2 次强制换路；每 5 题做一次 A/B 复盘。
