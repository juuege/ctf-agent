# forensics 技能卡

## 决策顺序
1. 识别载体：pcap / png / jpg / wav / 内存镜像。
2. 文件头校验与修复优先（改坏的头比对标准头）。
3. 提取后逐层走"再次路由"（提取出的内层文件按新题目处理）。

## 常见打法
- pcap：先统计协议/端点；HTTP 的请求体与响应体逐条提取；
  FTP 明文账号、Telnet 会话恢复、USB 键盘流量（1.5 字节键码序列转按键）。
- 图片隐写：LSB（低有效位）提取、附录数据（`binwalk` 等价：找第二文件头）、
  调色板异常；Stegsolve 手动层查看思路：各 bit-plane。
- 图片修复：改长宽字段（观察 CRC 言之有理的高度）。
- 音频：摩斯电码节奏、SSTV、频谱（频域密码/二维码）。
- 内存取证：volatility 的 pslist/filescan/dumpfile 流程思路；
  无环境时用字符串+结构签名手工定位。
