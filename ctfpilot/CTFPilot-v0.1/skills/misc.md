# misc 技能卡

## 决策顺序
1. 压缩包：先判"真加密/伪加密"（zip 的加密标志位），伪加密直接改头；
   真加密走 ARCHPR（掩码/字典）或已知明文攻击。
2. 文件修复：按魔数补头；多文件粘连用签名搜索逐个切出。
3. 编码杂项：全家桶顺序试 base 家族→hex→uuencode→ROT→Morse→jsfuck/brainfuck。

## 常见打法
- zip 伪加密：PK 头 0x09/0x00 标志位改写。
- zip CRC 碰撞：文件极短（<4 字节）时用已知 CRC 生成碰撞文件。
- 文件分离：搜索 `\x89PNG`、`PK\x03\x04`、`\xff\xd8` 等第二文件头。
- 社工字典：题面 token（比赛名/作者名）直接进字典前几名。
- 题目附件全黑图片：先查最小/最大像素异常。
- osint 类（默认离线不做实际联网）：输出搜索关键词与平台清单，由人执行。

## 提示词利用
题目描述里的每一个词都当 token 密码/密钥候选（与 xor-token 策略一致）。
